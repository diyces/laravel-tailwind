# Laravel Tailwind Portfolio

Full-stack portfolio platform built with Laravel 12 and Tailwind CSS 3, implementing project CRUD operations, contact form processing, and MySQL database integration.

---

## 🚀 Features

- Project CRUD (Create, Read, Update, Delete)
- Contact form with server-side validation
- Responsive UI using Tailwind CSS
- MVC architecture implementation
- MySQL database integration

---

## 🛠 Tech Stack

- Laravel 12
- Tailwind CSS 3
- MySQL
- Blade Template Engine
- JavaScript

---

## 🏗 Architecture

This project follows Laravel MVC architecture:
- Models handle data logic
- Controllers manage request handling
- Blade templates render UI

---

## 🔐 Security

- CSRF protection enabled
- Server-side validation implemented
- Input sanitized through Laravel validation

---

## 📈 Future Improvements

- Admin authentication
- Email notification for contact form
- Pagination for project listing
- API endpoint versioning

---

### Requirements

- PHP 8.2+
- Composer
- Node.js & NPM
- MySQL

## ⚙️ Installation

1. Clone repository

```bash
git clone https://github.com/diyces/laravel-tailwind.git
cd laravel-tailwind
```

2. Install dependencies

```bash
composer install
npm install
```

3. Setup environment file

```bash
cp .env.example .env
```

4. Configure database in `.env`

5. Generate application key

```bash
php artisan key:generate
```

6. Run migrations

```bash
php artisan migrate
```

7. Run development server

```bash
php artisan serve
```
